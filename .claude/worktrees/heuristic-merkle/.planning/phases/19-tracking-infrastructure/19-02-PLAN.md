```python
"""Pure correlation functions for matching *arr grabs to fetcharr searches.

All functions are pure (no I/O, no DB access). They accept search records
and grab events as inputs and return correlation results. Phase 20 handles
integration -- reading from DB and writing outcome updates.
"""

from __future__ import annotations

from dataclasses import dataclass
from datetime import datetime, timedelta

from fetcharr.models.arr import GrabEvent


@dataclass
class SearchRecord:
    """Minimal search record for correlation (extracted from DB row).

    Attributes:
        history_id: Primary key from search_history table.
        item_id: movieId (Radarr) or seriesId (Sonarr).
        searched_at: When the search was triggered (ISO string parsed to datetime).
        missing_count: Number of missing episodes at search time (Sonarr only, None for Radarr).
    """

    history_id: int
    item_id: int
    searched_at: datetime
    missing_count: int | None = None


@dataclass
class CorrelationResult:
    """Result of correlating grab history against a single search record.

    Attributes:
        history_id: Primary key of the search_history row.
        grab_count: Number of grab events matched to this search.
        matched_grabs: The GrabEvent objects that were matched.
    """

    history_id: int
    grab_count: int
    matched_grabs: list[GrabEvent]
```

The algorithm for `correlate_grabs`:

1. Parse all grab dates from ISO strings to datetime objects (handle both "Z" suffix and "+00:00" timezone formats by replacing "Z" with "+00:00" and using `datetime.fromisoformat`).

2. Sort searches by `searched_at` descending (most recent first). This is critical for the "most recent search gets credit" rule.

3. Create a set to track which grab IDs have already been claimed by a search.

4. For each search (in most-recent-first order):
   - Calculate window_end = search.searched_at + timedelta(minutes=tracking_window_minutes)
   - Find all grabs where:
     - grab.date (parsed) >= search.searched_at (grab happened after or at search time)
     - grab.date (parsed) <= window_end (inclusive boundary)
     - grab.id not in the claimed set
   - Add matched grab IDs to the claimed set
   - Create CorrelationResult with history_id=search.history_id, grab_count=len(matched), matched_grabs=matched

5. Return results sorted by history_id (or original search order) so the caller gets predictable ordering.

Key implementation detail: By iterating searches most-recent-first, the most recent search "claims" grabs in its window before older searches can. This implements the "most recent search gets credit" rule without complex overlap resolution.

```python
def _parse_iso(date_str: str) -> datetime:

    # *arr APIs return "Z" suffix; fromisoformat needs "+00:00"
    return datetime.fromisoformat(date_str.replace("Z", "+00:00"))
```
