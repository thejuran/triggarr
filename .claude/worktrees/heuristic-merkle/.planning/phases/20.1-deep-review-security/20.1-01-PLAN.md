Four targeted edits to fetcharr/db.py:

**DRSEC-01 -- row_factory race condition:**
In `get_recent_searches`, `get_search_history`, and `get_trackable_entries`, wrap the `db.row_factory = aiosqlite.Row` / `db.row_factory = None` pattern in `try/finally`. The `try` block starts immediately after setting `db.row_factory = aiosqlite.Row`, and the `finally` block resets it to `None`. This ensures that if any exception occurs during the query, the factory is always restored.

Pattern for each function:
```python
db.row_factory = aiosqlite.Row
try:
    async with db.execute(...) as cursor:
        rows = await cursor.fetchall()
finally:
    db.row_factory = None
```

Apply this to:
- `get_recent_searches` (lines ~224-231)
- `get_search_history` (lines ~298-317) -- note this function has TWO queries between the set/reset, both must be inside the try block
- `get_trackable_entries` (lines ~352-360)

**DRSEC-04 -- migration backup crash on fresh install:**
In `run_migrations`, guard the `shutil.copy2` call with `if db_path.exists():` so that fresh installs (no database file yet, since aiosqlite creates it on first operation) do not crash with FileNotFoundError.

Change:
```python
backup_path = db_path.with_suffix(f".v{current}-backup")
shutil.copy2(db_path, backup_path)
logger.info("Database backed up to {path}", path=backup_path)
```
To:
```python
backup_path = db_path.with_suffix(f".v{current}-backup")
if db_path.exists():
    shutil.copy2(db_path, backup_path)
    logger.info("Database backed up to {path}", path=backup_path)
```

**DRSEC-05 -- v1 migration DEFAULT value:**
In `_migrate_v1`, change the outcome column DEFAULT from `NULL` to `'searched'` so that newly added outcome columns get a meaningful default, and the v4 backfill (`WHERE outcome IS NULL`) only catches truly pre-v1 rows (rows that existed before the column was added).

Change:
```python
for col, default in (("outcome", "NULL"), ("detail", "NULL")):
```
To:
```python
for col, default in (("outcome", "'searched'"), ("detail", "NULL")):
```

**DRSEC-06 -- narrow suppress scope:**
Add `import sqlite3` at the top of db.py. Then in `_migrate_v1` and `_migrate_v2`, change `contextlib.suppress(Exception)` to `contextlib.suppress(sqlite3.OperationalError)`. This lets real errors (disk full, corruption, permissions) propagate instead of being silently swallowed.

Change both occurrences of:
```python
with contextlib.suppress(Exception):
```
To:
```python
with contextlib.suppress(sqlite3.OperationalError):
```
