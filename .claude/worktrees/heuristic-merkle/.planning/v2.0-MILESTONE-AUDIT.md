### Integration Finding

**startup.py validate_connections() bypasses request_timeout (DEBT-07 partial)**
- Temporary validation clients at boot don't receive `timeout=settings.general.request_timeout`
- Uses hardcoded 30s default for startup connection ping only
- All search cycle HTTP traffic correctly uses the configured timeout
- Severity: Low — only affects boot-time validation, not runtime behavior
- Fix: Add `timeout=settings.general.request_timeout` to RadarrClient/SonarrClient constructors in startup.py
