# UI redesign mockups

These mockups are the design reference for the "UI Redesign" milestone in [the roadmap](../../../.planning/ROADMAP.md#later-milestone-ui-redesign). Exported 2026-10-21 from the [Triggarr Redesign canvas](https://claude.ai/artifact/RWWVHSdV2TL51oU1EpwL8C), a claude.ai page that is private to the owner. The canvas is where the design gets edited; these files are the copy the repo reads.

- Desktop images are 1280 px wide and phone images 390 px wide, both at 2× pixel density.
- The HTML files are static and open in a browser. All styling is inline, so they give exact colors, spacing and type sizes. Fonts load from Google Fonts. Nothing in them is wired up.
- The numbers are live values from 2026-10-21. `[N]` and `[YOUR VALUE]` mark values that weren't captured, and the "[Example title]" rows only show what the Grabbed and Failed tags look like.
- Times in the History mockups are shown in local time. This assumes History currently displays UTC, which is milestone item 5 and still to be confirmed.
- These are not tests. Small differences in the implementation are fine; record any intentional ones in the milestone walkthrough.
