## Milestone Summary

**Decimal Phases:** None — all phases 60–63 were primary phases. Phase 63 was added mid-milestone as a gap-closure phase for HDR-06.

**Key Decisions:**
- D-01 (P60): Vendor only Phosphor Icons regular weight — saves ~800KB vs bundling all weights, adequate for all dashboard icon needs
- D-02 (P60): Keep logout as POST form (CSRF protection) styled visually as a link with Phosphor sign-out icon
- D-03 (P60): Use `font-geist-mono` utility (not generic `font-mono`) on version badge to enforce FONT-02 discipline
- D-04 (P60): Three-zone absolute-centered header layout (`w-64 shrink-0` zones + `absolute left-1/2 -translate-x-1/2` nav) gives precise alignment without flexbox justify hacks
- D-05 (P60): Defer HDR-06 (in-header favicon icon) rather than ship Mar 11 favicon PNGs with white-dot aliasing artifacts — deferral tracked and closed by Phase 63
- D-06 (P60): Connection pill uses htmx `load, every 30s` self-polling pattern to avoid threading health data through every route context
- D-07 (P61): Side-by-side horizontal mini bars on Grab Rate card (vs the old vertical stacked layout) — matches artifact spacing and makes per-app proportions directly comparable
- D-08 (P61): Preserve outer left-zone `gap-3 w-64 shrink-0` invariant when adding favicon icon so the version badge spacing stays identical to Phase 60
- D-09 (P61): Retain `.mini-bar` CSS class for backward compatibility even though the template no longer uses it (low cost to keep)
- D-10 (P61): Unreachable app cards replace the stats grid with a centered error message (no recessed sub-cards, no schedule row) — clearer error state
- D-11 (P62): Add `--font-mono: "Geist Mono"` CSS alias so `font-mono` utility class maps to Geist Mono without requiring Tailwind v4 theme restructuring
- D-12 (P62): Remove obsolete `timeline-item`, `timeline-dot`, `terminal-pane`, `scanline-overlay` classes entirely — they were not used by any current partial
- D-13 (P62): Activity rail uses position-based opacity fading (`opacity-75`/`opacity-60` by `loop.index`) not age-based — simpler to reason about, same visual effect
- D-14 (P62): TAILING badge uses border-container pattern (`bg-triggarr-bg border border-triggarr-border` wrapper) rather than solid fill — lighter visual weight on the log-viewer header
- D-15 (P62): Log level filter uses "Level: ALL" / "Level: ERROR" display format with `font-mono` to signal technical control
- D-16 (P62): `[GRAB]` log rows get `bg-triggarr-primary/10` highlight to make downloads visually distinct from info/warn/error chatter
- D-17 (P62): TAILING badge text changed from uppercase "TAILING" to title-case "Tailing" per UI-SPEC artifact (later reverted portions to uppercase based on artifact)
- D-18 (P62): Source tag colors migrated from raw Tailwind values to semantic tokens (triggarr-radarr / triggarr-sonarr) for consistency with the rest of the palette
- D-19 (P63): Regenerate 16×16 and 32×32 PNGs directly from SVG master via macOS `qlmanage -t` rather than from realfavicongenerator.net's downsampled pipeline — bypasses the re-aliasing path that caused the original white-dot artifact
- D-20 (P63): Discard the tool's regenerated `site.webmanifest` and keep the user's hand-cleaned SVG master — aligns with P63 D-01 (user supplies pre-cleaned master)
