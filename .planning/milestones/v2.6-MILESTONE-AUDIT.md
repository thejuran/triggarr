### Notable Observations (Non-breaking)

1. `/logout` not in EXEMPT_PREFIXES — requires authentication before deleting cookie (correct security behavior, undocumented)
2. `_sync_auth_state` not called on logout — functionally correct since auth_state reflects config state, not session state
3. Rate limiter `_login_failures` dict clears on restart — explicit accepted risk for homelab deployment
4. `copyApiKey` reads `input.value` instead of planned `data-key` attribute — functionally correct since copy button only renders when revealed
