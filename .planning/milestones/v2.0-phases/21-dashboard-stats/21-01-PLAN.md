In db.py, add an async function `get_dashboard_stats(db: aiosqlite.Connection) -> dict` that runs 3 queries in sequence on the shared connection:

1. **Effectiveness query**: Count outcomes from search_history grouped by app.
   ```sql
   SELECT app,
          COUNT(*) FILTER (WHERE outcome IN ('grabbed', 'partial')) AS grabbed_count,
          COUNT(*) FILTER (WHERE outcome != 'failed') AS total_count
   FROM search_history
   WHERE outcome IS NOT NULL
   GROUP BY app
   ```
   NOTE: SQLite does not support FILTER syntax. Use SUM(CASE WHEN ... THEN 1 ELSE 0 END) instead.
   - `grabbed_count`: outcomes in ('grabbed', 'partial') -- items where automation worked
   - `total_count`: all non-failed outcomes (searched + grabbed + partial + unresolved) -- the denominator excludes failed (API errors, not automation failures)
   - Compute overall_rate = sum(grabbed) / sum(total) * 100, per-app rates for Radarr and Sonarr

2. **Lifetime stats query**: SELECT all columns from lifetime_stats for both apps. Sum across apps for the totals displayed on cards.

3. **Time-to-grab query**: For entries with outcome='grabbed', compute average seconds between timestamp and the time the outcome was set. Since we don't store grab_detected_at separately, use a different approach: query search_history rows with outcome='grabbed' and detail field. The detail field for grabbed entries contains text like "grabbed: ..." -- but actually the elapsed time isn't stored. Instead, compute from the `timestamp` column (search time) and current time is wrong.

   REVISED APPROACH: The time-to-grab cannot be computed from existing columns because grab_detected_at is not stored. We need to add a `resolved_at TEXT` column to search_history via a new migration (v5). The `update_outcome_and_stats` function already writes the outcome -- add `resolved_at = datetime.now(UTC)` at the same time. For time-to-grab, query:
   ```sql
   SELECT AVG(
     (julianday(resolved_at) - julianday(timestamp)) * 86400
   ) AS avg_seconds
   FROM search_history
   WHERE outcome = 'grabbed' AND resolved_at IS NOT NULL
   ```

   Add migration v5 in db.py:
   ```python
   async def _migrate_v5(db: aiosqlite.Connection) -> None:
       """Add resolved_at column for time-to-grab calculation."""
       with contextlib.suppress(sqlite3.OperationalError):
           await db.execute("ALTER TABLE search_history ADD COLUMN resolved_at TEXT DEFAULT NULL")
       await db.commit()
   ```
   Register in MIGRATIONS dict as version 5.

   Update `update_outcome_and_stats` to also set `resolved_at`:
   ```python
   now = datetime.now(UTC).isoformat().replace("+00:00", "Z")
   await db.execute(
       "UPDATE search_history SET outcome = ?, detail = ?, resolved_at = ? WHERE id = ?",
       (outcome, detail, now, history_id),
   )
   ```
