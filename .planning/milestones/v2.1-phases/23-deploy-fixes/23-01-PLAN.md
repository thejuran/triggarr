Output: Updated config resolution, state paths, uvicorn root_path support, and tests proving both features work.

    - Test 1: When TRIGGARR_CONFIG_DIR is not set, CONFIG_DIR equals Path("/config") (backward compat)
    - Test 2: When TRIGGARR_CONFIG_DIR="/custom/path", CONFIG_DIR equals Path("/custom/path")
    - Test 3: CONFIG_PATH equals CONFIG_DIR / "triggarr.toml"
    - Test 4: STATE_PATH equals CONFIG_DIR / "state.json"
    - Test 5: DB path (derived in scheduler) follows state_path.parent, which is CONFIG_DIR
  </behavior>
  <action>
    1. In `triggarr/models/config.py`:
       - Read `TRIGGARR_CONFIG_DIR` from `os.environ.get("TRIGGARR_CONFIG_DIR", "/config")`
       - Set `CONFIG_DIR = Path(os.environ.get("TRIGGARR_CONFIG_DIR", "/config"))`
       - Change `CONFIG_PATH = CONFIG_DIR / "triggarr.toml"` (was hardcoded to `/config/triggarr.toml`)
       - Import `os` at the top

    2. In `triggarr/state.py`:
       - Import `CONFIG_DIR` from `triggarr.models.config`
       - Change `STATE_PATH = CONFIG_DIR / "state.json"` (was hardcoded to `/config/state.json`)

    3. In `entrypoint.sh`:
       - Read `TRIGGARR_CONFIG_DIR` with default `/config`: `CONFIG_DIR="${TRIGGARR_CONFIG_DIR:-/config}"`
       - Replace hardcoded `chown -R "$PUID:$PGID" /config` with `chown -R "$PUID:$PGID" "$CONFIG_DIR"`
       - Replace hardcoded `-d /config` in useradd with `-d "$CONFIG_DIR"`
       - Ensure the directory exists: `mkdir -p "$CONFIG_DIR"`

    4. No changes needed in `__main__.py` or `startup.py` -- they already import CONFIG_PATH and STATE_PATH from the modules being updated. The scheduler already derives db_path from `state_path.parent`, so it follows automatically.

    5. Write `tests/test_config_dir.py` with the behavior tests above. Use `monkeypatch.setenv` / `monkeypatch.delenv` to test env var handling. Since CONFIG_DIR is computed at module import time, tests must reload the module or test the logic directly (extract the env-reading into a function like `get_config_dir()` that can be called in tests, and have `CONFIG_DIR = get_config_dir()` at module level).

    IMPORTANT: To make this testable without module reload hacks, refactor the path resolution into a function:
    ```python
    def get_config_dir() -> Path:
        return Path(os.environ.get("TRIGGARR_CONFIG_DIR", "/config"))

    CONFIG_DIR = get_config_dir()
    CONFIG_PATH = CONFIG_DIR / "triggarr.toml"
    ```
    Tests can then call `get_config_dir()` with monkeypatched env to verify behavior, while the module-level constants work for production.
