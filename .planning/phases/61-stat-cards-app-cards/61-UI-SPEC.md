| Property | Value |

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px (p-1, gap-1) | Icon gaps, inline padding |
| sm | 8px (p-2, gap-2) | Compact element spacing, mini bar label margin |
| md | 12px (p-3, gap-3) | App card footer padding, sub-card gaps |
| lg | 16px (p-4, gap-4) | App card header/body section padding, stat card grid gaps |
| xl | 20px (p-5) | Stat card padding (all cards uniform p-5) |
| 2xl | 24px (gap-6, mb-6) | Stats row to app cards section gap |

Exceptions: `p-2.5` (10px) used on recessed sub-cards per artifact spec. `mb-4`/`mb-5` used for internal stat card and sub-card spacing per artifact.

## Typography

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Hero number | 32px (`text-[32px]`) | 700 (font-bold) | 1.0 (leading-none) | All stat card hero values (D-01: uniform, no text-[36px]) |
| Card title | 15px (`text-[15px]`) | 700 (font-bold) | 1.5 | App card instance titles |
| Stat value | 18px (`text-lg`) | 700 (font-bold) | 1.5 | Recessed sub-card numbers (Missing/Cutoff counts) |
| Label | 10px (`text-[10px]`) | 400 (normal) | 1.5 | Sub-card labels, connection pill text, mini bar labels |
| Label alt | 12px (`text-xs`) | 700 (font-bold) | 1.5 | Stat card category labels (tracking-widest uppercase) |
| Schedule | 11px (`text-[11px]`) | 400 (normal) | 1.5 | Schedule row text (font-mono) |
| Button | 12px (`text-xs`) | 600 (font-semibold) | 1.5 | Search Now button text |

Weights used: 400 (normal) and 700 (bold). Font-semibold (600) on buttons only.

## Interaction Contract

| Interaction | Behavior | Mechanism |
|-------------|----------|-----------|
| Stat card hover | Subtle background elevation to `#233346` + shadow | `.card-hover` CSS class (existing) |
| App card hover | Same elevation + shadow | `.card-hover` CSS class (existing) |
| Search Now click | htmx POST, replaces card via `outerHTML` | `hx-post` + `hx-target` + `hx-swap="outerHTML"` (existing wiring, preserved) |
| Search Now hover | Icon transitions to app-type color | `group` + `group-hover:text-triggarr-{color}` + `transition-colors` |
| Retry click | htmx POST, same as Search Now | Same mechanism |
| Stats auto-refresh | Polls every 30s | `hx-trigger="every 30s"` on `#stats-row` (existing, preserved) |
| App card auto-refresh | Polls every 5s | `hx-trigger="every 5s"` on card id (existing, preserved) |
| Connection pill pulse | Green dot pulses on connected cards | `.dot-pulse` CSS animation (existing) |

## CSS Changes Required

### Modify `.mini-bar` in input.css

The existing `.mini-bar` class conflicts with artifact specs. Two options:

**Option A (recommended):** Remove `.mini-bar` class entirely, replace with Tailwind utilities in template:
- Track: `w-full h-1 bg-triggarr-bg rounded-full overflow-hidden`
- Fill: `h-full bg-triggarr-radarr rounded-full` (via inline style for dynamic width)

**Option B:** Update `.mini-bar` to match artifact:
```css
.mini-bar { height: 4px; border-radius: 9999px; background: var(--color-triggarr-bg); overflow: hidden; }
.mini-bar > span { display: block; height: 100%; border-radius: 9999px; }
```

### New Token Needed

Add `triggarr-elevated` as a named token in `input.css` if not already present:
```css
--color-triggarr-elevated: #233346;
```

Note: Currently `triggarr-card-elevated` exists as `#233346`. The artifact uses `bg-triggarr-elevated`. Either add a `triggarr-elevated` alias or use `bg-triggarr-card-elevated` in templates. Recommend adding alias for artifact fidelity.
