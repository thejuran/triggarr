  <files>triggarr/state.py, tests/test_state.py, tests/conftest.py</files>
  <behavior>
    RED phase — write tests first, all must fail:

    1. test_nested_state_round_trip: Create a TriggarrState with radarr={"Default": AppState(missing_cursor=42, ...), "4K": AppState(missing_cursor=10, ...)}, save and load — both instances preserved with correct values.

    2. test_v22_state_migration: Write a v2.2-format state.json (flat {"radarr": {"missing_cursor": 5, "cutoff_cursor": 2, ...}}) to disk, load it — result should have radarr={"Default": {"missing_cursor": 5, "cutoff_cursor": 2, ...}}.

    3. test_is_v22_state_format_detection: Test _is_v22_state_format returns True for flat format (has "missing_cursor" directly under radarr), False for nested format (has instance names under radarr).

    4. test_orphan_cleanup: Load state with instance "OldInstance" that is NOT in settings, call cleanup_orphaned_instances — "OldInstance" is removed, configured instances remain.

    5. test_no_cross_contamination: Create state with two radarr instances "A" and "B" at different cursor positions. Modify A's cursor, save, reload — B's cursor unchanged.

    6. test_default_state_without_settings: _default_state() with no args returns empty dicts for radarr/sonarr.

    7. test_default_state_with_settings: _default_state(settings) returns per-instance entries at cursor 0 for each configured instance name.

    8. test_merge_defaults_nested: Write partial nested state (missing some AppState fields in one instance), load — missing fields filled with defaults.

    9. Update existing tests: test_state_round_trip, test_state_default_on_missing_file, test_state_atomic_write, test_state_creates_parent_dirs, test_state_corrupt_recovers_to_defaults, test_state_schema_migration_fills_missing_keys, test_state_schema_migration_preserves_all_existing — all must use the new nested format.

    GREEN phase — implement in state.py:

    1. Change TriggarrState to use `radarr: dict[str, AppState]` and `sonarr: dict[str, AppState]` instead of flat AppState.

    2. Add `_default_instance_state() -> AppState` returning fresh cursor-0 state.

    3. Update `_default_state(settings=None)` to accept optional Settings:
       - Without settings: return `TriggarrState(radarr={}, sonarr={}, search_log=[])`
       - With settings: populate per-instance entries from `settings.radarr.keys()` and `settings.sonarr.keys()`

    4. Add `_is_v22_state_format(data: dict) -> bool` — returns True when radarr/sonarr value has "missing_cursor" key directly (flat format).

    5. Add `_migrate_v22_state(data: dict) -> dict` — wraps each flat AppState into `{"Default": AppState}`.

    6. Update `_merge_defaults(loaded: dict) -> TriggarrState` for two-level-deep merge:
       - Iterate instance names in loaded["radarr"], merge each instance's AppState against `_default_instance_state()`.
       - Handle search_log as before.

    7. Update `load_state` to call `_is_v22_state_format` and `_migrate_v22_state` before `_merge_defaults`.

    8. Add `cleanup_orphaned_instances(state: TriggarrState, settings: Settings) -> TriggarrState` — removes instance keys not in `settings.radarr` / `settings.sonarr`. Collect keys to delete first, then delete (avoid mutation during iteration).

    9. Update conftest.py `default_state()` to work with the new signature.

    Per user decisions:
    - State keyed by instance name (not stable ID)
    - Orphan cleanup: immediate removal, no retention period
    - v2.2 migration assigns cursors to "Default" key
