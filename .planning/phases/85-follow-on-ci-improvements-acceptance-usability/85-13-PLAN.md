## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Reviewed head -> operator machine | Trusted mode runs the head's tests locally; untrusted heads are refused and recorded INCOMPLETE with no command run (isolated review is Phase 85.1) |
| PR-supplied base -> base grader | The base's checker is executed when a grader changed; only a base on origin/main is accepted |
| Operator flag -> trust decision | `--trusted` must be backed by GitHub PR ownership or this machine's own commit history |
| Changed grader -> its own verdict | A PR can modify the checker that grades it |

| T-85-39a | Spoofing | Fork commit fetched and branched locally, or a forged owner email, passing as trusted | mitigate | Emails and branch membership are never trust signals; reflog subjects are written only by this machine's git; same-commit-both-paths regression test |
