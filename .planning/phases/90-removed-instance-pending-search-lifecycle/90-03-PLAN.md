<objective>
Move Radarr and Lidarr pending-search selection from display name to stable instance ID, closing the path by which a new same-name instance inherits a removed instance's searches.

Purpose: this is the safety half of RMINST-03 for Radarr and Lidarr (D-01). It holds whether or not any close-out has run: a row is only ever selected by a tracking check running under that row's own stable ID. (Work still queued for the removed instance itself, which carries the removed ID, is turned away by plan 90-07.)
Output: changed selection and crediting in `triggarr/tracking.py`; five existing tests that assert the old behaviour re-expressed; one existing isolation test given distinct stable IDs; new tests for all three apps.
</objective>
