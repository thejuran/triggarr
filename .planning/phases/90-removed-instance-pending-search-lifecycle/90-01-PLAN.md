Give `triggarr/db.py` one definition of "pending" and one named terminal outcome for searches of a removed instance, and make every existing query treat that outcome as finished and uncounted.

Retires the backlog item "Shared pending-outcome rule" instead of adding a seventh copy.
Output: constants and SQL fragments in `triggarr/db.py`, the six copies replaced, the stats exclusion, and regression tests in `tests/test_db.py`.
</objective>
