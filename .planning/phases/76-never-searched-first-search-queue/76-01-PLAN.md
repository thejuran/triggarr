<objective>
Build the pure dispatch core and the persisted state substrate for never-searched-first search, test-first.

This plan creates `prioritize_batch` (the single pure function that implements never-searched-first selection, top-up, mark-on-attempt, prune-to-eligible, and pass-completion detection) and swaps the `AppState` cursor fields for ordered searched-logs. Purpose: `prioritize_batch` is a pure function with a fully-defined I/O contract (design spec §6) and an exhaustive test matrix (spec §8) — the clearest TDD unit in the phase. Writing the unit matrix and the cold-start oracle RED-first locks the behavior-preservation guarantee before any caller depends on it.

Output: `prioritize_batch` in `engine.py`; `missing_searched`/`cutoff_searched` fields on `AppState` with empty-log defaults; the full `prioritize_batch` unit matrix + cold-start-equivalence oracle test in `test_search.py`; searched-log round-trip, default-state, and back-compat-load tests in `test_state.py`.
