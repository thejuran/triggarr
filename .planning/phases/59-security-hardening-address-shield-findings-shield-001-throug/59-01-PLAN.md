  <behavior>
    Rate limiter tracks failed login attempts per IP using a module-level dict with monotonic timestamps.

    Cases:
    - 9 failed attempts from same IP -> login_post processes normally (not rate-limited)
    - 10 failed attempts from same IP within 5 min -> login_post returns 200 with login.html containing error "Too many login attempts, try again in N minutes"
    - 10 failed attempts, then 5 min passes -> login_post processes normally again
    - Successful login -> not counted as failure, does not increment rate limit
    - Different IPs -> tracked independently (IP A at limit does not affect IP B)
    - _check_rate_limit("1.2.3.4") after 10 failures -> returns (True, retry_after_seconds)
    - _check_rate_limit("1.2.3.4") after 0 failures -> returns (False, 0)
    - _record_failure("1.2.3.4") -> appends time.monotonic() to _login_failures["1.2.3.4"]
    - _reset_rate_limiter() -> clears _login_failures dict
  </behavior>
  <action>

    GREEN: Implement the rate limiter:

    1. Add three module-level items to triggarr/web/routes.py (above the login_post function, around line 1120):

    2. Add helper functions:
       ```python
       def _check_rate_limit(ip: str) -> tuple[bool, int]:
           """Check if IP is rate-limited. Returns (is_limited, retry_after_seconds)."""
           now = time.monotonic()
           timestamps = _login_failures.get(ip, [])
           timestamps = [t for t in timestamps if now - t < _WINDOW_SECONDS]
           _login_failures[ip] = timestamps
           if len(timestamps) >= _MAX_ATTEMPTS:
               oldest = min(timestamps)
               retry_after = int(_WINDOW_SECONDS - (now - oldest)) + 1
               return (True, retry_after)
           return (False, 0)

       def _record_failure(ip: str) -> None:
           """Record a failed login attempt for rate limiting."""
           now = time.monotonic()
           if ip not in _login_failures:
               _login_failures[ip] = []
           _login_failures[ip].append(now)

       def _reset_rate_limiter() -> None:
           """Clear all rate limit state. Used by test fixtures."""
           _login_failures.clear()
       ```
