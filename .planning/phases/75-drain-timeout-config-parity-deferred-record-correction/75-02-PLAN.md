<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser form POST → settings handler | operator-supplied form value crosses into the config model and atomic TOML write |
| config model → settings.html render | persisted value crosses back out to the rendered page |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-75-04 | Tampering | settings POST shutdown_drain_timeout | mitigate | safe_float(..., 1.0, 3600.0) clamps the posted value before it reaches the model; the model's ge=1.0 is a second defense; bounded write protects the shutdown drain from a malicious/typo 0 |
| T-75-05 | Cross-Site Scripting | settings.html drain input render | accept | `{{ shutdown_drain_timeout }}` is a float from the typed config model (not free-form user text); Jinja2 autoescaping is on; no user-controlled string is rendered |
| T-75-06 | Information Disclosure | settings.html help text | accept | Help text names a non-secret env var only; no token/hash/secret/PII rendered; SecretStr discipline unaffected (no auth field in scope) |
| T-75-SC | Tampering | npm/pip/cargo installs | accept | No new packages installed; reuses existing safe_float (Plan 75-01), Jinja2, and the settings POST path |
</threat_model>
