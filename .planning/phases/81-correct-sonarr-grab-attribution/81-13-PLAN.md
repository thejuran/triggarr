- Pagination: `ArrClient.get_paginated` (triggarr/clients/base.py:170-224) requests pageSize = client page size, locks totalRecords from page 1, stops when page * pageSize >= totalRecords. So a raw count > pageSize that equals totalRecords means at least two pages were fetched and concatenated.

- Tag scope: `_resolve_tag_scope` (engine.py:792-905); a configured tag that is not found, or a failed tag fetch, makes that queue unresolved and the cycle sets it to None: no dispatch, counts frozen (engine.py:1349-1352). refresh leaves an unresolved queue's counts at their previous values (engine.py:2050-2075).
- Dispatch: the only Sonarr search call is `SonarrClient.search_season` (sonarr.py:172-180), called only at engine.py:1482 and 1527, inside `for season in batch`. `prioritize_batch` returns an empty batch when there are no eligible seasons (engine.py:353-354) or batch_size <= 0 (engine.py:365). An inactive queue is still fetched and filtered (engine.py:739-761, 1366-1460), so its counts are computed.
