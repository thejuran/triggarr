| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-85.1-38 | Spoofing | One attempt's records standing in for another (B18) | mitigate | Gate reads exactly one prefix; meta/boundary head and attempt must match the prefix; no globbing (grep-gated) |
| T-85.1-39 | Elevation of privilege | Skipping the cross-grade when the grader changed | mitigate | base-status required and bound whenever audited_inputs_changed_in_diff is non-empty |
| T-85.1-40 | Repudiation | Behavioral silence mistaken for proof | mitigate | Probes only downgrade the verdict; label "supplementary … (not proof)" |
| T-85.1-41 | Information disclosure | Probe planting host secrets | mitigate | Probe files hold random tokens only, live outside every mount in a temp dir, and are deleted with it |
| T-85.1-42 | Tampering | Symlinked record files | mitigate | Gate reads via safe_read_regular_file |
| T-85.1-43 | Information disclosure | `--verify-boundary` interrupted or failing while a credential-bearing container's removal is unconfirmed, losing the warning | mitigate | Ledger finalizer _print_boundary_cleanup_escalation prints the unverified verdict with the full-ID `docker rm -f` command before the exception re-raises; regressions for interrupt and probe-preparation failure combined with unconfirmed removal |
