<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Untrusted head/base -> operator machine | PR content and its base commit are attacker-controllable for forks |
| GitHub API -> runner | PR state and CI evidence are read over the API |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-85.1-15 | Elevation of privilege | Head code executing on the host | mitigate | Only git plumbing reads into memory; no checkout/worktree/archive; test asserts no execution argv and no planted file on disk |
| T-85.1-16 | Tampering | Git attribute drivers running during diff | mitigate | GIT_SAFE_PREFIX plus --no-textconv --no-ext-diff --no-color on every diff |
| T-85.1-17 | Elevation of privilege | Fork-controlled base supplying grader Python (B13) | mitigate | Fresh origin/main fetch, harness HEAD must equal MAIN_SHA, base must be ancestor; malicious-base regression asserts no `git show <base>:` and no sys.executable call |
| T-85.1-18 | Spoofing | CI evidence from another head, a failed latest run, or a missed page | mitigate | Only the latest `CI ready` for exactly --head counts; --paginate --slurp flattened; malformed pages fail closed |
| T-85.1-19 | Spoofing | Prompt injection closing the input block | mitigate | Random per-run fence regenerated until absent from input; single-pass substitution |
| T-85.1-20 | Denial of service | Oversized input | mitigate | Per-file and total byte limits; oversize recorded INCOMPLETE by the caller |
</threat_model>
