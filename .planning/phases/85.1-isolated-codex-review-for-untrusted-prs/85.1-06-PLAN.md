## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Untrusted prompt text -> Codex | Prompt injection may try to make Codex use tools |
| Codex output -> grading | The event stream and report are untrusted model output |
| Operator -> runner | No flag may bypass the gate |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-85.1-21 | Elevation of privilege | Codex reaching an untrusted head without isolation | mitigate | Mandatory verify_isolation_boundary before the only launch seam; non-verified -> exit 3, no codex/docker start argv (tested) |
| T-85.1-22 | Tampering | Tool use hidden behind a "complete" report | mitigate | audit_event_types fails closed on any non-allowlisted item or event type, independent of the checker |
| T-85.1-23 | Elevation of privilege | Base or PR grader judging its own change (B13) | mitigate | Cross-grade only from MAIN_SHA, support check before the boundary, end-to-end malicious-base regression |
| T-85.1-24 | Repudiation | Silent incomplete run or a reservation with no status | mitigate | Every post-reservation path writes a status stub; final stdout line says escalate, never clean; exit 3 |
| T-85.1-25 | Tampering | Partially written output files | mitigate | _write_json_atomic (temp + os.replace) for new JSON outputs |
