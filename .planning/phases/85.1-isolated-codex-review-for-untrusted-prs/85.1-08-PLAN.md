<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Host sign-in file -> container | The only secret that crosses into the container (D-06) |
| Container-writable dirs -> host reader | /out and /codex-home are writable by the untrusted-content process |
| Docker CLI environment -> container | Host env could leak through -e or the CLI's own env |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-85.1-31 | Information disclosure | Symlink/FIFO planted in /out or /codex-home to read host files or hang the runner (B15) | mitigate | docker rm -f before any read; O_DIRECTORY|O_NOFOLLOW dir fd, O_NOFOLLOW|O_NONBLOCK file open, fstat S_ISREG, size bound; real symlink/FIFO regressions |
| T-85.1-32 | Denial of service | Mid-run token refresh signing out the host (D-08) | mitigate | 24h freshness preflight (owner re-login when stale), sha256 compare after the run, INCOMPLETE with re-login message, never copied back |
| T-85.1-33 | Information disclosure | Credential values in logs, messages or evidence | mitigate | Structural checks only; messages carry key names/ages; `.boundary.json` holds no paths or hashes of the credential; test asserts no token in messages |
| T-85.1-34 | Information disclosure | Host env leaking via the docker CLI | mitigate | docker_env passes only PATH, HOME, DOCKER_HOST, DOCKER_CONTEXT, DOCKER_CONFIG; no -e forwarding except CODEX_HOME=/codex-home |
| T-85.1-35 | Tampering | Starting a different container than the one inspected (TOCTOU) | mitigate | The container ID returned by the verified boundary is the one started; created-not-started containers cannot be reconfigured by the PR |
| T-85.1-36 | Information disclosure | Credential copy left on disk | mitigate | Per-run dirs removed in finally on every path including KeyboardInterrupt; tested |
| T-85.1-37 | Information disclosure | Owner session exfiltrated over open egress if container and tool-disabling both fail | accept | D-07 owner decision recorded verbatim in the contract (Plan 85.1-04); egress restriction backlogged (D-05) |
</threat_model>
