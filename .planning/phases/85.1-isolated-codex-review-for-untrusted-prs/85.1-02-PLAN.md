## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-85.1-04 | Spoofing | Inspection-only status claiming complete without a real boundary verification | mitigate | Completeness requires boundary verdict "verified" bound to the same head and attempt; anomalous complete claims are blocked outright with no fallback path |
| T-85.1-05 | Tampering | Evidence from another attempt or head standing in | mitigate | Existing head/base binding, boundHere on status and base-status, boundary.head/attempt binding, fallback codex_out must match the checked OUT |
| T-85.1-06 | Elevation of privilege | A grader change in the PR escaping cross-grading | mitigate | baseRequired uses the union of the meta claim and readiness's own git recomputation; missing/incomplete/unbound base-status blocks |
| T-85.1-07 | Repudiation | Two completeness formulas drifting apart | mitigate | One exported predicate used by both scripts plus the parity test over a shared fixture table |
| T-85.1-08 | Elevation of privilege | Trusted head accepting weaker untrusted evidence | mitigate | Trusted heads count only trusted-local-tests; inspection-only and untrusted-refused records never open a trusted fallback |
</threat_model>
