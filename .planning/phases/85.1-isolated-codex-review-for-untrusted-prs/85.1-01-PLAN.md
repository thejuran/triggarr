<objective>
Teach the Codex report checker an explicit, caller-declared inspection-only grading mode, so a review of an untrusted head (which by design runs no commands and reproduces nothing) can be graded complete on its own terms without weakening the trusted-mode hollow-report guard.

Purpose: Phase 85 D-07 (delivered for untrusted heads by this phase). The runner (Plans 85.1-05/06) grades every inspection-only report with this mode, and the trusted-main cross-grader must support it, or the run fails closed.
Output: `--review-mode trusted|inspection-only` in `tests/codex_report_status.py` with tests.
</objective>

| T-85.1-02 | Elevation of privilege | Hollow trusted-mode report passing because the guard was loosened | mitigate | Trusted branch kept byte-for-byte; regression test test_default_mode_keeps_hollow_report_guard |
| T-85.1-03 | Spoofing | Inspection-only report claiming reproduced findings or commands it could not run | mitigate | Two explicit inspection-only rejection reasons, tested by substring |
