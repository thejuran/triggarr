## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Dependabot PR head -> operator machine | A real untrusted head is reviewed |
| Owner -> merge/acceptance | Only the owner merges and approves |
| Evidence -> public repository | Raw outputs are committed publicly |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-85.1-47 | Elevation of privilege | Running the live review with the branch's grader before merge | mitigate | Task 1 blocks on the owner's merge; the runner refuses unless its HEAD is the freshly fetched origin/main (D-02) |
| T-85.1-48 | Repudiation | Reporting an INCOMPLETE live run as complete, or silent retries | mitigate | Completion only via `--completion-gate` exit 0; retries need owner consent; STATE says blocked otherwise |
| T-85.1-49 | Spoofing | Using a closed or historical head as proof | mitigate | Proof PR must be OPEN with CI ready success for its current head (D-09); runner refuses non-open PRs |
| T-85.1-50 | Denial of service | Host login invalidated by the run | mitigate | Owner `codex login` right before; post-run `codex login status` and a trivial authenticated call recorded |
| T-85.1-51 | Information disclosure | Secrets in committed raw outputs | mitigate | Contract secret scan before commit; $HOME grep gate; no credential contents recorded |
| T-85.1-52 | Elevation of privilege | Claude merging or approving | mitigate | Merge and acceptance are owner actions only (CLAUDE.md, owner-cli-acceptance) |
