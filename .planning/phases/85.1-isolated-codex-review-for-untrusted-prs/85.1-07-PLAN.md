|----------|-------------|
| Review container -> host | Only three per-run directories are mounted |
| Docker daemon -> runner | `docker inspect` output is checked, never trusted to be safe by default |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-85.1-26 | Elevation of privilege | Extra mount, root user, Docker socket, host namespace, privileged mode | mitigate | Exact expected-configuration comparison with one mutation test per field |
| T-85.1-27 | Information disclosure | Host env vars (tokens, SSH agent) leaking into the container | mitigate | Only CODEX_HOME=/codex-home is set; Config.Env names limited to CONTAINER_BASE_ENV; canary env limited to base plus HOSTNAME/PWD; SHLVL-style additions rejected |
| T-85.1-28 | Tampering | Codex using a modified output schema | mitigate | Hash-verified per-run copy mounted read-only; in-container hash re-checked by the canary (B17) |
| T-85.1-29 | Information disclosure | Host paths in evidence, mounts or forwarded env | mitigate | host_exposure_problems: protected host paths never as mount sources or env values for either container, only as inert canary positional arguments; reasons and canary results report them by marker only |
| T-85.1-30 | Information disclosure | Unrestricted egress | accept | D-04 owner decision; NetworkMode must be exactly bridge with no published ports; recorded as not enforced |
