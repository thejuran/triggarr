## Sampling Rate

- **After every task commit:** quick run command plus `uv run ruff check tests/`
- **After every plan wave:** full suite command
- **Pre-merge phase gate:** full suite green, plus a local `--verify-boundary [--with-probes]` run against the actually built review image. This is recorded as pre-merge evidence (D-03).
- **Post-merge phase gate (separate, D-02/D-03):** the live inspection-only review of PR #47 (or the next open Dependabot PR, D-09), graded by `origin/main`'s checker, must return COMPLETE through `--completion-gate`. An authenticated minimal host Codex call must succeed afterwards (D-08/D-11). This is a verification gate, not a plan: the plans end with 85.1-10, then the once-per-phase BM review, paired Codex pass, vibe-check decision and push/PR run as usual (PC-04).
- **Max feedback latency:** 120 seconds
