> Per-phase validation contract for feedback sampling during execution. Source: 85.1-RESEARCH.md § Validation Architecture.

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | pytest (`uv run`, asyncio_mode=auto) plus `node --test` for `.github/scripts/*.cjs` |

| **Full suite command** | `uv run pytest tests/ -x -q && uv run ruff check triggarr/ tests/ && node --test .github/scripts/*.test.cjs .claude/plugins/planchk-router/test/planchk-router.test.mjs` |
| **Estimated runtime** | ~120 seconds |

---

## Sampling Rate

- **After every task commit:** quick run command plus `uv run ruff check tests/`
- **After every plan wave:** full suite command
- **Pre-merge phase gate:** full suite green, plus a local `--verify-boundary [--with-probes]` run against the actually built review image. This is recorded as pre-merge evidence (D-03).
- **Post-merge phase gate (separate, D-02/D-03):** the live inspection-only review of PR #47 (or the next open Dependabot PR, D-09), graded by `origin/main`'s checker, must return COMPLETE. The host Codex login must still work afterward (D-08/D-11).
- **Max feedback latency:** 120 seconds
