<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| filesystem (state.json) -> load_state | file contents are untrusted (could be corrupted or tampered) |
| load_state -> log sink | warnings must not carry file contents |
| load_state -> filesystem (set-aside copy) | new file written in the config directory |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-87-11 | Denial of Service | load_state startup crash | mitigate | isinstance(data, dict) guard before any .get(); parametrized tests over list/number/null/string/bool/float roots |
| T-87-12 | Information Disclosure | D-10 warning | mitigate | Warning built from path, a type description and exception type/message only; never exc.doc or parsed values; sentinel tests assert contents absent |
| T-87-13 | Information Disclosure | state.json.corrupt permissions | mitigate | shutil.copy2 preserves the source mode; permissions test asserts no bits beyond the source's 0o600 |
| T-87-14 | Tampering (symlink write-through) | set-aside destination | mitigate | Copy to a mkstemp temp in the same directory then os.replace onto the fixed name, so an existing symlink is replaced rather than followed |
| T-87-15 | Denial of Service (disk growth) | repeated corruption | mitigate | One fixed destination name, overwritten each time; exactly-one-copy test (D-08) |
| T-87-16 | Denial of Service | copy failure blocking startup | mitigate | try/except OSError around mkstemp, copy2 and os.replace; fd closed immediately after mkstemp; guarded temp cleanup in finally; recovery continues (D-11); parametrized test over all three failure points asserts no leftover file and unchanged descriptor count |
</threat_model>
